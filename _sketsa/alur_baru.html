③ Halaman Periksa Syarat — grafik SPSS + khas PLS

Menu tersendiri di navigasi atas. Tiap grafik diberi kalimat tafsir + cara cek di SPSS/PLS sendiri.

Sisa tersebar rata?

Heteroskedastisitas · SPSS & PLS
Aman

Sebaran titiknya rata dari kiri ke kanan — syarat regresi terpenuhi. Tidak perlu tindakan.

Cara cek sendiri: Analyze → Regression → Linear → Plots → pindahkan ZPRED ke X dan ZRESID ke Y.

Sisa menyebar normal?

Normalitas · SPSS & PLS
Aman

Titiknya menempel garis — sisa menyebar normal. Aman untuk uji hipotesis.

Cara cek sendiri: Analyze → Regression → Linear → Plots → centang Normal probability plot.

Sisa ikut garis normal?

Normal P-P · versi garis
Aman

Garis data mengikuti garis lurus acuan — tidak ada penyimpangan ekor.

Khas PLS: SmartPLS tidak menyediakan P-P plot — pakai aplikasi ini sebagai pengganti cepat.

Bobot tiap item cukup kuat?

Outer Loading · khas PLS
Aman

Semua batang melewati garis 0,70 — tiap item layak mewakili konstruknya.

Di SmartPLS: Calculate → Outer Loadings. Di bawah 0,70 → item itu perlu diperiksa.
Rencana grafik lengkap: 6 untuk SPSS (hetero, normalitas, histogram sisa, linearitas, VIF, p-value) + 4 khas PLS (outer loading, AVE, reliabilitas, VIF inner). Yang mulai dikerjakan: heteroskedastisitas + normalitas sesuai ACC Bos.

⚠️ Catatan jujur: karena datanya kita buat sendiri, grafik hampir selalu "aman". Supaya mahasiswa tetap belajar mengenali yang rusak, nanti ditambah tombol "buat data sakit" (bareng modul KLINIK).
